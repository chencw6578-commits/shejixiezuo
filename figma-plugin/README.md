# Figma 导出插件（设计协作）

把 Figma 里选中的画板直接导出到你的「设计协作」网站：在 Figma 选中画板 → 点上传，两步完成。
首选团队与项目后，插件会记住选择，下次打开自动带出。

## 上手

### 1. 在网站生成「导入令牌」

1. 打开网站，进入 **团队 → 团队设置**。
2. 选择作用范围：
   - **全部团队**（默认推荐）：插件里可以先选团队、再选项目；
   - **仅当前团队**：令牌只能导出到这一个团队。
3. 点 **生成导入令牌**，复制 `imp_` 开头的令牌。明文只显示这一次（服务端只保存哈希），丢了就重新生成。
4. 不用了随时点 **撤销**，插件再用会立即返回 401。

### 2. 安装插件

1. 打开 Figma 桌面端，菜单 **Plugins → Development → Import plugin from manifest…**。
2. 选择本仓库的 `figma-plugin/manifest.json`。
3. 之后在 **Plugins → Development → 设计协作 · 导出** 打开插件窗口。

### 3. 首次打开：粘贴令牌

第一次打开只有「粘贴导入令牌」一个输入框。粘贴第 1 步复制的 `imp_` 令牌，点 **保存并继续**。
令牌保存在本机 Figma 插件存储里，下次打开直接进入主界面，**不需要重复粘贴**：

- 网络失败、超时、CORS 或服务端 5xx：令牌**保留**，界面提示「连接失败，令牌已保留」并提供 **重试**，重试成功即进入主界面；
- 只有服务端明确返回 **401 / 令牌已撤销** 时才会清空本地令牌并回到粘贴界面；
- 想换令牌：**高级设置** 里的「更改令牌」入口（不会每次打开强制出现）。

### 4. 日常使用：在 Figma 选中画板 → 点上传

- 中部列表是 **Figma 当前选中画板的只读镜像**：Figma 里选中哪些画板，这里就显示哪些，插件里不需要也不能勾选。
  在 Figma 里改变选中后会自动同步（旧版本 Figma 可重新运行插件刷新）。
- 没有选中任何画板时，列表会提示「请在 Figma 里选中要导出的画板」，底部按钮禁用。
- 顶部「导出到」显示当前的 **团队 / 项目 / 编组**。点 **更改** 才展开三个下拉：
  - 切换 **团队** 会自动清空并刷新项目；
  - 切换 **项目** 会自动刷新编组；
  - 编组可选「未分组」、已有编组，或 **+ 新建编组** 并填名称。
- 点底部 **导出并上传（N 个画板）**。进度条会显示读取节点 → 导出图片 → 上传，以及当前第几个画板；
  失败会在原地显示原因和 **重试**，不会跳新页面。
- 成功后显示「已导入 N 个画板 / M 个节点」和 **在网站中打开** 链接，可直接再传一次。

主界面常驻显示 **平台 / 倍率 / 位图切图** 三项（在顶部目标条下方）：

- 平台决定查看器的逻辑单位：Android → dp、iOS → pt、Web → px；
- 倍率 1x / 2x / 3x 决定 PNG 切图清晰度，默认 Android/iOS 2x、Web 1x；
- **位图切图默认关闭**（只导结构最快，1229×883 这类大画板也只需几秒）；需要位图时再勾选，
  勾选后界面会提示「大画板导出切图较慢（单张最长 90 秒）」；单张超过 5MB 会自动跳过图片并提示，画板与节点仍正常导入。

**高级设置**（默认折叠）只保留服务器地址与「更改令牌」。

> 逐画板上传：位图体积大，插件一个画板一次请求，避免单次请求过大失败。
> 重复导入同一个 Figma 画板会**原位更新**，不会产生重复画板。

## 仅导出 JSON（离线备份）

底部次要入口 **仅导出 JSON** 会导出所选画板的 JSON，可复制或下载。
网站项目页的导入面板也支持粘贴这份 JSON（`POST /api/import/figma-json`）。

## 换服务器地址 / 部署到公网域名

插件界面跑在 Figma 的沙箱 iframe 里，请求会同时受 **Figma manifest 白名单** 和 **服务端 CORS** 两道限制。换地址时必须同时改两处，只改一处就会被拦：

1. 插件 **高级设置 → 服务器地址** 改成新地址（必须完整写 `http://` 或 `https://`，不能只写域名）；
2. `manifest.json` 的 `networkAccess` 里加上新域名，例如：

```json
"networkAccess": {
  "allowedDomains": ["https://design.example.com"],
  "devAllowedDomains": ["http://localhost:4000"],
  "reasoning": "导出向导需要把画板 JSON 与 PNG 位图上传到协作网站"
}
```

改完 manifest 必须重新 **Plugins → Development → Import plugin from manifest…**（或重启 Figma）才生效，开发插件不会热更新。
**换域名要同步改 `networkAccess`**：漏改时 Figma 会直接拦截请求，插件提示「该域名未在插件 manifest 中授权（networkAccess）」。

3. 服务端：`/api/plugin/*` 已对 `null`（Figma 沙箱 iframe 的 Origin）、`https://www.figma.com`、`https://figma.com`
   与本地开发来源（`http://localhost:*` / `http://127.0.0.1:*`）开放跨域，并正确处理 `OPTIONS` 预检、允许 `Authorization` 头。
   如果你的来源不在白名单，需要改 `server/src/routes/plugin.ts` 里的 `pluginCors`。

## 常见问题

### 项目下拉是空的

插件会区分三种情况并给出不同文案：

- **该团队还没有项目，请先在网站创建**：数据问题，去网站项目页新建项目；
- **令牌无权访问该团队（权限问题）**：令牌是「仅当前团队」范围，换团队会被 403 拒绝；
  到网站团队设置重新生成「全部团队」范围的令牌；
- **未归属团队**：网站里早期未分配团队的项目会归到这里，只有「全部团队」令牌可见。

### 点了插件没反应

1. 确认 Figma 桌面端（浏览器版对开发插件支持有限）。
2. **Plugins → Development** 里应直接看到「设计协作 · 导出」条目；如果它变成了子菜单，
   说明 `manifest.json` 里误加了 `menu` 字段（本仓库没有）。
3. `manifest.json` 必须包含 `"documentAccess": "dynamic-page"`；缺了会在运行前加载整份文件，大文件看起来像没反应。
4. 修改插件文件后必须重新 **Import plugin from manifest…** 或重启 Figma，开发插件没有自动热更新。

### 上传失败 / 401

- **401**：令牌填错或已在网站撤销 → 回团队设置重新生成并粘贴。
- **403**：令牌作用范围不允许访问该团队/项目 → 换「全部团队」范围的令牌，或改选令牌所属团队。
- **连不上服务器，请确认网站已启动、地址正确**：服务没起、端口或地址错（默认 `http://localhost:4000`）；
  先在浏览器打开 `http://localhost:4000/api/health`，能看到 `{"ok":true,…}` 就说明服务正常。
- **该域名未在插件 manifest 中授权（networkAccess）**：地址能解析但不是 Figma 允许的域名；
  把新域名写进 `manifest.json` 的 `networkAccess`，重新导入插件（见上文「换服务器地址 / 部署到公网域名」）。
- **插件主线程 90 秒没有响应**：单张切图导出超过 90 秒。先在 Figma 里关闭「位图切图」重试（只导结构）；
  仍需要位图时降低倍率（3x → 2x）或拆分大画板，再用「重试」继续（已成功的画板不会重做）。
- **位图超过 5MB**：降低倍率（3x → 2x）或关闭位图导出后重试。

### 编组里看不到刚导出的画板

插件的编组属于项目里的「Figma 插件导入」设计稿；上传成功后编组下拉会自动刷新。
网页端手工建在其它设计稿下的编组不会出现在插件的编组下拉里。

## 数据与安全

- 令牌只在服务端存 sha256 哈希；明文仅在生成时返回一次，不写入日志、不写进前端构建产物。
- 插件把令牌、服务器地址、三级选择存在 `figma.clientStorage`（本机 Figma 插件存储），不会发给第三方。
- 位图切图按 `scale` 存为 PNG 资源，画板缩略图同步更新。

## 开发者备注

- `code.js`：主线程，读画板、导出 JSON（schemaVersion 1）、`figma.exportAsync` 导出 PNG（base64）、`figma.clientStorage` 偏好。
  心跳按阶段给静默上限：读节点 30 秒 / 单张切图 90 秒 / 单板上传 60 秒；切图每次导出前先发一条「第 N / M 张」进度；
  base64 每 256KB 一片（`image-chunk`）回传，UI 侧拼装后再上传；每步耗时同时打到 Figma 控制台（`[timing]`）。
- `ui.html`：单屏界面与所有网络请求（`fetch` + `Authorization: Bearer imp_…`）。
- 网站接口：
  - `GET /api/plugin/me` → 令牌所属团队与作用范围；
  - `GET /api/plugin/teams` → 可访问团队（id、name、项目数；「全部团队」令牌含 `unassigned` 未归属团队）；
  - `GET /api/plugin/teams/:teamId/projects` → 该团队项目（越权 403）；
  - `GET|POST /api/plugin/projects/:id/groups`、`POST /api/plugin/import`（越权 403）。
- 已用 Node `vm` 模拟 `figma` 对象验证主线程逻辑与请求体结构；**尚未在真实 Figma 客户端实测**（环境无 Figma 桌面端）。
- 文档依据：Figma Plugin API（`figma.showUI` / `figma.ui.postMessage` / `figma.exportAsync` / `figma.clientStorage` / `manifest.documentAccess`），核对日期 2026-11-08。
